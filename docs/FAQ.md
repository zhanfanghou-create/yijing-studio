# 排障手册

> README 里的 FAQ 解决「这是什么」，这份解决「它不动了」。

---

## 一、启动

### 双击后没有窗口

1. 看 `%APPDATA%\yijing-studio\launcher.log`，最后 20 行通常就写着原因。
2. 最常见的是 GPU 子进程崩溃（日志里会停在 `GPU process isn't usable. Goodbye.`）。
   启动器默认已经关了硬件加速，如果你手动开过 `--gpu`，去掉它。
3. 还是不行，用终端起一次，能看到完整堆栈：

   ```bash
   cd <安装目录>/resources/app
   npx electron .
   ```

### 窗口起来了但画布是白的

按顺序排查：

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 顶栏显示「0 节点」 | 文档没加载成功 | 看 `%APPDATA%\yijing-studio\projects\` 下是否有 json；删掉损坏的那个再开 |
| 顶栏正常但画布空白 | 视口在很远的地方 | `Ctrl+0` 适应画布 |
| 整页白 + 控制台报错 | 构建产物损坏 | 重装 |

### 打开老项目提示「节点尺寸已校正」

这是预期行为。卡片尺寸跟 catalog 走，画布不支持手动改尺寸，
老项目打开时会按当前 catalog 校正一次，素材库也会补上分桶字段。

## 二、模型

### 配置检测说「未安装」，但文件明明在

配置检测读的是安装目录下 `models/` 的清单文件，不是扫盘。
如果手动拷贝过模型，需要让安装器重新登记一次：在配置检测里点「一键修复」，
它会校验文件大小与清单是否一致。

### 下载卡在 0% 或速度是 0

1. 换源：配置检测里会显示当前使用的源，ModelScope 不通会自动换 HF 镜像。
2. 手动验证网络：

   ```bash
   curl -I https://modelscope.cn
   curl -I https://hf-mirror.com
   ```

3. 已经下了一半的文件在 `models/.partial/` 下，重开下载会接着传，不会从头开始。

### 下载完成后提示「校验失败」

说明文件大小或哈希对不上，通常是下载中断导致。删掉 `models/.partial/` 里对应的分片重下。

### 视频模型 34.4GB，硬盘不够

视频模型是可选装（NF4 量化版，不是官方那份 171GB 的全量）。只装对话 + 图像（约 50GB）
也能用画布的全部编辑功能，只是点「生成视频」时会提示模型缺失。

## 三、生成

### 节点底部写「服务未启动」

点顶栏「配置检测」，它会告诉你缺哪个服务。能一键拉起的会直接拉起。
媒体服务首次加载模型要几十秒，进度会回到节点上。

### 节点底部写「显存不足」

视频模型的显存占用跟分辨率、时长强相关：

| 变量 | 影响 |
| --- | --- |
| 分辨率 | 1080p 大约 720p 的 2.2 倍显存 |
| 时长 | 线性增长（按时长 × 24 算帧数） |

先降到 720p、5 秒跑通，再往上加。这不是软件限制。

### 选了 12 秒，但生成出来是 5 秒

0.1.0 里不应该出现这个。时长的口径只有一处（`VIDEO_DURATION_MIN/MAX`），
生成前只做 1–30 的硬裁剪。如果真遇到，看节点底部的 warn 文案 —— 它会写清被改成了多少、为什么。

### 首尾帧模式下点生成没反应

首帧或尾帧缺失会**直接拒绝提交**（不白花电费），节点上会写明缺哪一个。
尾帧候选只列已经有产物的图片或角色形象节点。

### 图生视频没连参考图

不会报错，而是按文生视频提交，并在节点上留一条 warn。
这是刻意的：多数时候用户只是忘了连线，直接失败会更让人困惑。

## 四、导出

### 导出报「找不到 ffmpeg」

成片导出依赖本机 ffmpeg，二选一：

1. 把 `ffmpeg.exe` 放进 PATH；
2. 放到安装目录的 `resources/ffmpeg.exe`。

> 本项目不随安装包分发 ffmpeg。请自行获取，并注意你所用构建的许可（LGPL / GPL）。

### 导出很慢

- 同容器同编码 → 流拷贝，秒级；
- 编码不一致 → 自动重编码 H.264 / AAC，耗时约等于视频时长 × 1.5。

想快就把所有镜头用同一个模型、同一档分辨率出片。

### 导出报「片段为空 / 路径不存在」

镜头顺序里有一个节点的产物被删了。打开成片预览，逐个点镜头条定位，把失效的摘掉。

## 五、性能

### 画布卡顿

| 现象 | 处理 |
| --- | --- |
| 节点超过 80 个开始掉帧 | 用「分组」把不看的区块折起来；或用素材库收纳 |
| 缩放时文字发虚 | 正常，画布是 DOM 渲染，zoom < 0.5 时字会小到 5px，`Ctrl+0` 回全览再推近 |
| 拖动节点时掉帧 | 关掉小地图（底栏工具条最右） |

### 磁盘占用增长快

产物素材按内容 sha1 命名并自动去重，但**删除节点不会删文件**（避免误删被别处引用的产物）。
定期清理 `%APPDATA%\yijing-studio\assets\` 里没被任何项目引用的大文件。

## 六、网络与隐私

### 怎么确认它真的没联网

三层都能验：

1. 预设层：设置里看不到任何云端通道；
2. 存储层：`%APPDATA%\yijing-studio\providers.json` 里不可能出现非回环地址；
3. 请求出口：把任意通道的地址改成一个外网域名，点生成，会立刻报

   ```
   本应用只调用本机模型，api.openai.com 不是本机地址，请求已停止
   ```

### 能不能完全断网使用

模型装好之后可以。断网只会影响「下载模型」和「检查更新」。

### 会上传我的素材吗

不会。素材只在本机读写，模型请求全部打到 `127.0.0.1`。
项目文件是明文 json，在 `%APPDATA%\yijing-studio\projects\`，你可以自己打开看。
